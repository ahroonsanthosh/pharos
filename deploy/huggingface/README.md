# Pharos

Pharos works out where a drone is by matching its downward camera against free
satellite and aerial maps, so it keeps going when GPS is jammed, spoofed or missing.

This Space is a public demo: start a **demo flight** from **New feed**, or upload your
own footage. Anyone visiting sees the same feeds. For live drone feeds, run Pharos on
your own laptop.

Source, results and how it works: https://github.com/ahroonsanthosh/pharos
